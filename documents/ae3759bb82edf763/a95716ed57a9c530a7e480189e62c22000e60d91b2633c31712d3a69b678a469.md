## Model service

Model Studio provides ready-to-use model services, including the proprietary Qwen series and third-party models such as DeepSeek, Kimi, and GLM. See [Recommended models](https://www.alibabacloud.com/help/en/model-studio/models).

*   **Qwen flagship models**:

    *   Qwen-Max: The highest-performing model in the Qwen series, suited for complex, multi-step tasks.

> The latest qwen3.8-max delivers significant reasoning improvements over its predecessor. Recommended.

    *   Qwen-Plus: Balances performance, speed, and cost — **recommended** for most scenarios.

    *   Qwen-Flash: Low-cost and low-latency — suited for simple tasks that require fast responses.

*   **Multimodal coverage**: Includes text generation, visual understanding, image generation, video generation, speech recognition and synthesis, and embedding.

*   **Domain-specific models**: Models for long-text processing, translation, data mining, intent recognition, role-playing, and deep research.

## Billing

Activating Model Studio is free. Costs apply only when you invoke models. See [Billable items and pricing](https://www.alibabacloud.com/help/en/model-studio/model-pricing).

*   **Model inference** — Models such as deepseek-v3.2-exp and other large language models are billed based on the number of tokens generated. You can use savings plans to offset the cost.
*   **Knowledge Base (RAG)** — Knowledge Base is an independent retrieval-augmented generation feature billed by specification duration and model calls. It does not support savings plans or resource plans.

**Note**

Model inference and Knowledge Base are separate features in Model Studio with independent billing.

### Free quota for new users

New users receive a free quota in the Singapore region to try model invocation.

*   Users who have not completed their profile cannot continue using the service after the free quota is depleted. They must [complete their profile](https://account.alibabacloud.com/intl/supply_userinfo/index.htm#/basic/security/mobile) to switch to pay-as-you-go billing.
*   Users who have completed their profile are automatically switched to pay-as-you-go billing after the free quota is depleted. To avoid unexpected charges, enable the [Free quota only](https://www.alibabacloud.com/help/en/model-studio/new-free-quota#d1cb80ac11i92) feature — the service stops when the quota is depleted.

For more information, see [Free quota for new users](https://www.alibabacloud.com/help/en/model-studio/new-free-quota).

### Payment methods

Model calls are billed per minute. For supported payment methods, see [Payment methods](https://www.alibabacloud.com/help/en/user-center/instruction-of-payment-management/).

### View bills and usage

*   **Billing details**: Go to the [Billing Details](https://usercenter2-intl.console.alibabacloud.com/finance/expense-report/expense-detail-by-instance) and [Cost Analysis](https://usercenter2-intl.console.alibabacloud.com/expense-manage/expense-analyze) pages.
*   **Call statistics**: After a model call occurs, you can view the monitoring charts at the **minute** level. Log in to the [Monitoring](https://modelstudio.console.alibabacloud.com/model/telemetry) page, select **Operations Management**>**Monitoring** in the left navigation pane to enter the monitoring overview page, set query conditions (for example, time range, workspace, etc.), find the target model in the **Models** area and click **View Details** to view call volume, token consumption, success rate, and other statistics. For more information, see [Model monitoring](https://www.alibabacloud.com/help/en/model-studio/model-telemetry).
*   **Coding Plan usage**: If you are subscribed to Coding Plan, view quota consumption on the [Coding Plan page](https://modelstudio.console.alibabacloud.com/ap-southeast-1/subscription/coding-plan). Coding Plan uses a fixed monthly fee with a monthly request quota for AI coding tools. See [Coding Plan overview](https://www.alibabacloud.com/help/model-studio/coding-plan).

## FAQ

Q: Is my data secure? Will Alibaba Cloud Model Studio use my data for training?

A: Alibaba Cloud protects data privacy and will never use your data for model training. All data transmitted when building applications or training models is encrypted. See [Security certifications and privacy](https://www.alibabacloud.com/help/en/model-studio/privacy-notice).

Q: How many regions is Model Studio available in? What are the differences between regions?

Q: How can I avoid automatic charges?

A: Model Studio uses pay-as-you-go billing with no **automatic deduction**. To avoid charges:

*   **Delete API keys**: Go to the [Model Studio console](https://modelstudio.console.alibabacloud.com/), select your region, go to the [API Key](https://modelstudio.console.alibabacloud.com/model/settings/api-key) page, and delete all API keys.
*   **Stop all model calls** in applications, agents, and workflows — including scheduled tasks and background processes.
*   **Turn on**[Free quota only](https://www.alibabacloud.com/help/en/model-studio/new-free-quota#d1cb80ac11i92)**(new users only)**: On the model details page, enable this switch. Service stops when the quota is depleted, preventing paid usage. Applies only to models in the Singapore region within the validity period.
*   **Set up cost monitoring and alerts**: View [Billing Details](https://usercenter2-intl.console.alibabacloud.com/finance/expense-report/expense-detail-by-instance) and [Monitoring](https://modelstudio.console.alibabacloud.com/model/telemetry), and set up [high-spending alerts](https://billing-cost.console.alibabacloud.com/expense-manage/cost-warning/alarm-threshold) to catch abnormal spending.
*   **Coding Plan**: This plan offers a fixed monthly fee and monthly request quota, replacing pay-as-you-go charges. Use the dedicated base URL and API key for the Coding Plan when making calls — otherwise, model calls are charged pay-as-you-go. See [Coding Plan overview](https://www.alibabacloud.com/help/model-studio/coding-plan).

Q: How to use Qwen3 or DeepSeek?

A:

1.   **Try it online**: Open the [Model Studio console](https://modelstudio.console.alibabacloud.com/), select your region, go to the [Models](https://modelstudio.console.alibabacloud.com/model/market) page, and click a model. (DeepSeek is available only in the China (Beijing) region.)
2.   **Call models via API**: See [Make the first call to a Qwen API](https://www.alibabacloud.com/help/en/model-studio/first-api-call-to-qwen).
3.   **Use developer tools (such as Claude Code)**: See [Connect to clients or developer tools](https://www.alibabacloud.com/help/en/model-studio/use-chat-client-or-development-tool).
