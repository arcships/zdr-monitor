## 1. 服务关系

**1.1 第三方部署模型，指由外部模型服务商直接提供计算服务、推理能力和模型输出，通过 TokenHub 向您提供使用入口或接入能力的人工智能模型。**该等模型并非由我们研发、训练或部署控制，其模型输出由相应的外部模型服务商直接生成、负责。**第三方部署模型的范围，以 TokenHub 正式发布并向您展示的模型清单、控制台、产品文档或模型服务说明页面所载信息为准。**

1.2 **为免疑义，主服务协议定义的“腾讯云自部署模型”（即由外部模型服务商开发、训练、开源或授权，但由腾讯云在腾讯云侧部署和运维的模型）不适用本说明。**

1.3 您使用第三方部署模型时，即与相应外部模型服务商直接建立服务关系，我们仅就直接提供的平台接入、身份鉴权、路由转发、计量计费、数据传输、安全管理和技术支持等事项，依主服务协议承担相应责任。**TokenHub 作为模型即服务（Model as a Service，MaaS）平台，不构成第三方部署模型本身的研发者、训练者、运营者或控制者，不就该等模型向您承担责任，仅就其直接提供且可控制的平台层服务，按照主服务协议及明确承诺承担相应责任**。

## 2. 责任限制

**2.1 我们就 TokenHub 自有平台服务作出的服务等级协议（SLA）及服务承诺，仅适用于我们自行提供的平台层服务能力，不适用于第三方部署模型服务。我们不对第三方部署模型的可用性、稳定性、准确性、响应速度、推理能力或其他服务能力作出明示或默示保证。**

**2.2 第三方部署模型服务由相应外部模型服务商提供并独立承担责任。因外部模型服务商自身原因导致第三方部署模型发生以下问题的，不构成我们的违约，我们不承担相应的赔偿或服务等级协议（SLA）违约责任：**

**（1）服务性能下降，或技术缺陷，例如限流、降速、排队、输出不准确等。**

**（2）服务中断，或服务不可用，例如服务系统故障、容量不足、接口调整、模型版本变更、内容安全策略拦截、服务下线等。**

**（3）输出违法违规内容或侵权内容。**

**（4）其他因外部模型服务商导致的问题。**

**前述情形发生时，我们将尽合理努力协助您了解情况或提供替代方案建议。**

**2.3 在适用法律允许的最大范围内，如我们须就本说明项下第三方部署模型相关事项向您承担赔偿责任的，我们的累计赔偿总额以您在责任事件发生前十二（12）个月内就该第三方部署模型实际向我们支付的服务费用为上限。涉及多个第三方部署模型的，以您就各模型实际向我们支付的服务费用之和为上限。**

**2.4 为免疑义，以下费用或权益不计入前述赔偿责任上限：免费试用额度、赠送 Token、促销权益、未实际支付对价的额度、外部模型服务商直接向您收取的费用、非因使用第三方部署模型而产生的平台服务费用、税费、代扣代缴费用以及其他非因使用第三方部署模型而产生的费用。您未就相应第三方部署模型向我们实际支付费用的，我们不承担赔偿责任，或赔偿责任以人民币100元为限。**

## 4. 模型调整与权益保障

4.1 因法律法规或监管要求、外部模型服务商调整、TokenHub 业务运营需要等合理原因，我们有权对第三方部署模型进行新增、替换、限制、降级、暂停或下线等调整，并相应更新可用模型清单。

4.2 对于第三方部署模型的重大调整（例如下线），除紧急安全事件、监管要求或外部模型服务商立即停止服务等无法提前通知的情形外，我们将依法在商业上合理可行的范围内通知您。**因第三方部署模型调整导致您无法继续使用该模型或需要调整业务系统的，不构成我们的违约，但我们仍将履行通知、必要协助及未使用权益处理义务。**

**4.3 因特定第三方部署模型调整导致您实际已支付对价但尚未使用的 Token 或权益无法继续用于该模型的，我们将按照以下规则处理：**

**（1）已支付对价但尚未使用的 Token 或权益对应的费用，将退还至您的账户。**

**（2）赠送 Token、免费试用额度等您未支付对价的部分，不适用前款安排；但我们将为您提供替代模型推荐或权益迁移等合理方案，具体安排以届时的通知为准。**

4.4 我们可在合理范围内向您提供替代模型推荐、迁移建议或必要技术协助，但不保证替代模型与原模型在能力、成本、输出质量、适用性、兼容性等方面完全一致。
