# Data Handling in Generative AI Agents

Does the OCI Generative AI Agents service retain customer queries, responses (chats), or knowledge bases for model training?
No, the OCI Generative AI Agents service doesn't use customer's knowledge base or user's chat data for model training. Chat or knowledge base data isn't employed to enhance general use cases for the service. Also, the service doesn't retain any chat data beyond the duration of the user's session.

Does the OCI Generative AI Agents service retain customer-provided queries and retrieved context used for chatting on the Large Language Models (LLMs)?
The OCI Generative AI Agents service retains customer-provided queries and retrieved context used for chatting with Large Language Models (LLMs) during the user's session. However, this data isn't stored beyond the session. Also, the service doesn't use customer chat data or knowledge base data for model training. For the managed knowledge base, data is stored in isolation and not mixed among customers, ensuring maximum security. While the data is used during the session for best performance, it's not retained or repurposed afterward.
