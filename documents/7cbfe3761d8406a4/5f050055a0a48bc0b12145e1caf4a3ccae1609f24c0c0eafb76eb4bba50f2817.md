Title: Overview - Alibaba Cloud

URL Source: https://www.alibabacloud.com/help/en/model-studio/token-plan-personal-overview

Markdown Content:
Token Plan Personal Edition is an AI large model subscription service for individual developers. It uses Credits as a unified billing unit and supports text models, multimodal models, and Harness tools. It is compatible with mainstream AI coding and agent tools.

**Note**

Token Plan Personal Edition is currently available only in the **Singapore** region.

## Key features

*   **Unified Credits billing**: Use Credits to pay for different models and Harness tools under a single billing unit.
*   **Multimodal model support**: Covers text generation, reasoning, visual understanding, image generation, speech synthesis, real-time voice conversation, speech recognition, video generation, and more.
*   **Harness tool integration**: Supports web search, text-to-image search, image-to-image search, web scraping, and code interpreter.
*   **Usage packs**: Purchase usage packs after exceeding your quota to continue using the service without restrictions.
*   **Compatible with multiple tools**: Works with mainstream AI coding and agent tools such as Claude Code, Cursor, Qwen Code, Qoder, Qoder CN, and OpenClaw.

## Credits billing mechanism

**Note**

Credits are deducted using tiered deduction coefficients by model. Multimodal models such as video generation consume significantly more Credits per call than text conversations. Pay attention to the following two points:

*   **High consumption per call**: Credits for video generation increase with the duration and resolution, which may quickly use up a large part of your quota. For your first attempts, use a shorter duration and a lower resolution, check the actual consumption per call on the subscription page usage details in the console, and then decide on further usage.
*   **Batch settlement for asynchronous tasks**: Credits for asynchronous tasks such as video generation are settled after the task completes, rather than deducted at submission. If you submit multiple asynchronous tasks within a short period, the Credits settled together after all the tasks complete may cause you to reach the quota limit quickly.

### Billing description

The Credits consumed per request are dynamically determined by model type, token usage, thinking mode, and tool calls. Refer to the [subscription page](https://modelstudio.console.alibabacloud.com/ap-southeast-1/subscription/token-plan/personal) usage details in the console for actual consumption.

### Deduction order

1.   Credits consumed by each call count toward the 7-day quota.
2.   When either quota is reached, the service is paused. You can purchase Extra Bundles for additional Credits not subject to window limits, wait for the corresponding window period to end and the quota to reset, or upgrade your plan for higher quota limits.

### Quota reset

You can use the quota reset feature to reset the 7-day quota to zero. After resetting, Credits consumed in the current window are cleared and quota accumulation restarts from zero.

Quota resets consume reset counts. Users who subscribed before August 5, 2026 will be granted a one-time 7-day quota reset starting August 5, 2026, which can be used as needed within its validity period. For details, see the [Model Upgrade Notice](https://www.alibabacloud.com/en/notice/detail?id=2074). For subsequent reset counts, stay tuned for official announcements or events.

## Subscription management

### Upgrade

You can upgrade from a lower-tier plan to a higher-tier plan. The upgrade price is prorated based on the remaining subscription period. After the upgrade, the quota is immediately raised to the new plan tier.

The Credits granted upon upgrade are not the full billing-cycle quota of the new plan tier. Instead, they are prorated based on the price difference you actually paid and the number of days remaining in your current billing cycle:

```
Prorated Credits = (Total upgrade price difference / 30 days) × Remaining valid days
```

For example, if you upgrade partway through a billing cycle, the Credits you receive reflect only the remaining valid days of the current cycle, not a full new-tier allotment.

### Renewal

You can switch to a different renewal duration and renew for multiple cycles at once.

*   **Manual renewal**: You can choose a different renewal duration and renew for multiple cycles.
*   **Auto-renewal**: When enabled, the system automatically deducts fees and renews before expiration.

Renewal only extends the subscription validity period and does not add quota to the current billing cycle.

### Other

*   The Personal Edition does not currently support unsubscription.
*   If you repurchase after your subscription expires, your API Key will change and you will need to reconfigure it in your tools. You can find your new API Key in the [**My Subscription**](https://modelstudio.console.alibabacloud.com/ap-southeast-1/subscription/token-plan/personal) page in the console under the API Key section.

## Important information before subscribing

1.   **Usage scope**: This plan is intended for interactive use only within coding tools and agent tools such as Claude Code, Cursor, Qwen Code, Qoder, Qoder CN, and OpenClaw. It must not be used for automation scripts, custom application backends, or any non-interactive batch call scenarios. Models are accessed through the tools' extension mechanisms (Skill, Slash Command, or Agent); calls initiated interactively within a tool are considered normal use. Using the plan API Key for calls outside the allowed scope will be considered a violation or abuse, and may result in subscription suspension or API Key banning.
2.   **Region and data transfer**: For Token Plan, the only available region is Singapore and the only available deployment mode is Global, which means the model inference will be performed globally. The prompts and model outputs will involve cross-border data transfer, and you are responsible for ensuring that your use of the Token Plan complies with applicable laws and regulations.
3.   **Account usage policy**: The plan is for the exclusive use of the subscriber and sharing is prohibited. Account sharing may result in restricted subscription benefits.
4.   **Purchase limit**: Each verified identity is limited to one subscription per edition, and can hold the Personal Edition and Team Edition at the same time.
5.   **Device usage**: Token Plan Personal Edition is intended for use on a single device per individual user. Sharing the API Key with others may be considered a violation and result in suspension.
6.   **RAM user identity verification**: RAM users do not need to complete identity verification separately. As long as the Alibaba Cloud account has completed identity verification and has assigned the RAM user a seat and API call permission, the RAM user can use Token Plan normally.
