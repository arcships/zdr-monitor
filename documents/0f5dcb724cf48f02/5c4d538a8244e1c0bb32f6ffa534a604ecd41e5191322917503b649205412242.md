Title: Token Plan overview - Alibaba Cloud

URL Source: https://www.alibabacloud.com/help/en/model-studio/token-plan-overview

Markdown Content:
Token Plan is an AI model subscription service offered by Alibaba Cloud Model Studio. It uses Credits as a unified billing unit and supports various AI coding and agent tools. Token Plan offers Personal Edition and Team Edition in two editions, meeting the needs of individual developers to enterprise teams.

**Note**

Token Plan is currently available only in the **Singapore** region. Switch the region to **Singapore** in the upper-left corner of the [Model Studio console](https://modelstudio.console.alibabacloud.com/ap-southeast-1/subscription/token-plan) to purchase and use.

## Product overview

Token Plan uses a unified Credits deduction mechanism, allowing you to use a single subscription across mainstream AI coding and agent tools such as Claude Code, Cursor, Qwen Code, Codex, Qoder, Qoder CN, and OpenClaw. It supports text generation, image generation, video generation, speech recognition, real-time voice conversation, and other models, as well as Harness tools such as web search and code interpreter.

*   **Personal Edition**: Designed for individual developers, it offers four plan tiers: Lite, Essential, Standard, and Pro, with a Credits limit per subscription month. Higher tiers provide larger quotas.
*   **Team Edition**: Designed for teams and enterprises, it offers three seat tiers: Standard seat, Pro seat, and Max seat. It supports multi-seat management, usage analytics, and guarantees that your data will not be used for model training.

## Plan quotas

### Personal Edition

Personal Edition uses a monthly quota system, measured in Credits:

*   **Monthly quota**: A 30-day subscription cycle starts from the subscription date. When cumulative consumption within the subscription cycle reaches the plan quota, the service is paused until the next subscription month.

When the monthly quota is reached, the service is paused. You can purchase Extra Bundles for additional capacity, or wait for the quota to reset at the start of the next subscription month. Unused quota within a subscription month does not carry over to the next cycle.

### Team Edition

Team Edition uses a monthly quota system. The billing cycle is calculated from the subscription date as a subscription month, not a calendar month. For example, if you subscribe on June 4, the subscription is valid until the 4th of the following month. The full monthly quota is granted in a single batch at the start of each subscription month, not distributed daily. Renewing only extends the subscription period and does not add extra quota to the current billing cycle. Each seat's monthly quota is available within the billing cycle, and unused quota does not carry over. When the monthly quota is exhausted, API calls are blocked. You can purchase shared quota packs to add more capacity.

## FAQ

### Can I purchase both Personal Edition and Team Edition?

Yes. The same Alibaba Cloud account can hold both Personal Edition and Team Edition subscriptions simultaneously. They are billed independently.

### About Coding Plan

Coding Plan and Token Plan are two independent subscription products. Migration or upgrades between them are not supported. Coding Plan Lite stopped accepting new purchases on March 20, 2026, and stopped renewals and upgrades on April 13, 2026. Coding Plan Pro was a limited-quantity offering and is no longer available once sold out. We recommend **Token Plan**, which supports more models and Harness tools.
