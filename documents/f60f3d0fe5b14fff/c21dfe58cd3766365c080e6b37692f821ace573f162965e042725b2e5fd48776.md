## How Usage Is Charged

If you use all of the agent usage included with your tier, you can add paid credits and keep working. Amp charges those credits for the actual model and tool usage in each thread. For individuals and non-enterprise workspaces, Amp does not add a markup to providers’ API prices. Paid credits require no paid tier or commitment. Non-model tools such as web search also consume paid credits.

For example, if a thread uses $2 of Anthropic API usage and $0.50 of OpenAI API usage, Amp deducts $2.50 from your credits.

Orbs use a separate usage allowance. Amp bills orb usage by the minute and pauses an orb 5 minutes after the agent stops working or 20 minutes after you last interacted with it, whichever comes later. A paused orb costs nothing. See [When an Orb Pauses](https://ampcode.com/docs/orbs/sizes-and-costs#when-an-orb-pauses) for what counts as work and what keeps an orb running. You can choose any orb size. Larger orbs use the allowance faster, and smaller orbs use it more slowly.

You can buy credits and check your balance in [user settings](https://ampcode.com/settings), in [workspace settings](https://ampcode.com/workspace), or by running `amp usage`. Purchased credits expire twelve months after purchase. Workspace members share paid workspace credits.

## Enterprise

Enterprise uses custom pricing. It also adds controls and support:

*   SCIM directory sync
*   Admin controls
*   [Minimal data retention](https://ampcode.com/docs/enterprise/minimal-data-retention)
*   Advanced thread visibility controls
*   Per-user cost controls
*   MCP registry allowlists
*   Managed user settings
*   Controls to prevent workspace members from using personal model routing
*   User groups for cost attribution and per-group thread visibility options (on request)
*   Configurable thread retention (on request)
*   IP allowlisting for workspace access (on request, extra charges apply)
*   Regional endpoint support for bring-your-own-key model providers

For more information about Amp Enterprise security features, see the [Amp Security Reference](https://ampcode.com/security).

To start using Amp Enterprise, [contact the Amp team](https://ampcode.com/contact-sales).

## Notes

For detailed cost information about a thread, click the `$` price on the right sidebar from any thread’s page.

You can also ask Amp to [explain your usage](https://ampcode.com/news/explain-usage), including why a thread used more tokens and how its credits were spent.

Invoices are issued through Stripe, which supports adding your VAT ID or other tax information.

See the [latest update about Amp Free](https://ampcode.com/news/amp-free-is-ad-free).
