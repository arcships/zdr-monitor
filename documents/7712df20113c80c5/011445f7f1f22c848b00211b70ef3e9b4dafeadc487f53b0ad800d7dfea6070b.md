Title: 什么是零数据保留（ZDR）？ - Kimi API 开放平台

URL Source: https://platform.kimi.com/docs/guide/zero-data-retention

Markdown Content:
了解 Kimi 开放平台面向企业客户提供的零数据保留（ZDR）模式。

零数据保留（Zero Data Retention，ZDR）是 Kimi 开放平台为企业客户提供的数据保护模式。开通后，你的请求内容只在生成响应的过程中存在于系统中，响应返回后即行清除，不做留存（法律法规要求除外）。

## ZDR 模式下的数据处理

*   **提示词（Prompt）**：仅用于当次推理，响应返回后清除。
*   **模型响应内容**：返回后清除，不做留存。
*   **模型训练**：企业客户数据不用于模型训练。

> Kimi 开放平台默认不使用企业客户数据训练模型，ZDR 在此基础上进一步取消内容留存。

## 安全说明

ZDR 只改变数据的留存方式，不改变平台的使用规范。内容安全审核等自动化保护措施对全部流量照常生效；如发现滥用行为，平台有权依据使用政策处置，包括终止 ZDR 服务。

## 谁可以开通？

ZDR 按需开放给企业客户。如果你的业务涉及敏感数据，或所在行业对数据留存有监管要求，可联系销售申请评估。

## 常见问题

### ZDR 会影响 API 的使用方式吗？

不会。ZDR 是服务端的数据处理策略，接口、参数、计费完全不变。

### ZDR 模式下还能排查问题吗？

平台不保留请求内容，无法对单次请求的内容做回溯排查，请在你自己的系统中留存请求日志。

### ZDR 适用所有数据类型吗？

通过直接文件上传方式提交的图像或视频，使用 Kimi Hosted Agents 托管智能体的数据，零数据留存无法保证。安全日志、账单记录等运营数据不属于零留存范围；第三方模型、连接器、插件等不受本协议约束。
