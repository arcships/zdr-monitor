# Index a Repository

Copy page Copy page

Index your repositories from the DeepWiki settings page so Devin can power Ask Devin and DeepWiki with an up-to-date understanding of your code.

Copy page Copy page

Indexing your repositories allows Devin to understand your codebase and enables powerful features like [Ask Devin](https://docs.devin.ai/work-with-devin/ask-devin) and [DeepWiki](https://docs.devin.ai/work-with-devin/deepwiki). This quick guide walks you through the indexing process.

Repository indexing is separate from [environment configuration](https://docs.devin.ai/onboard-devin/environment). Indexing enables code search and understanding features, while environment configuration sets up Devin’s development environment.

## [​](https://docs.devin.ai/onboard-devin/index-repo#index-your-repository)

Index Your Repository

1.   Go to [app.devin.ai](https://app.devin.ai/) and ensure you’re logged into your organization
2.   Click on **Settings** in the sidebar to access your organization settings
3.   Select **DeepWiki** and scroll to the **Repositories** section, which lists the repositories your organization has already indexed
4.   Click **Add**

![Image 4: DeepWiki Repositories section with the Add button](https://mintcdn.com/cognitionai/q6UtfWkPOjxD5XwB/images/quickstart/Org-Repositories-List.png?fit=max&auto=format&n=q6UtfWkPOjxD5XwB&q=85&s=93b8143498cea43d50c954cf19eea73d)

1.   In the **Add repositories** dialog, check every repository you want Devin to index, then click **Add repositories**

![Image 5: Add repositories dialog with multiple repositories selected](https://mintcdn.com/cognitionai/q6UtfWkPOjxD5XwB/images/quickstart/Index-Branch.png?fit=max&auto=format&n=q6UtfWkPOjxD5XwB&q=85&s=6ad4f2fb7be59ca959667723d149be64)

1.   Wait for indexing to complete — newly added repositories show **Indexing…** until they’re ready, which may take a few minutes depending on repository size

![Image 6: Repositories list showing repositories that are indexing and repositories that are indexed](https://mintcdn.com/cognitionai/q6UtfWkPOjxD5XwB/images/quickstart/Index-In-Progress.png?fit=max&auto=format&n=q6UtfWkPOjxD5XwB&q=85&s=c1c2b183f079ced828872604fcd46179)

Devin indexes each repository’s default branch. To index additional branches, click a repository in the list to open its **Indexed branches** page, then use the **Add branch** dropdown to pick a branch.

![Image 7: Indexed branches page for a repository with the Add branch dropdown](https://mintcdn.com/cognitionai/q6UtfWkPOjxD5XwB/images/quickstart/Index-Manage-Branches.png?fit=max&auto=format&n=q6UtfWkPOjxD5XwB&q=85&s=ae6aae90f5acdcc862a73591487bfd02)

Once complete, you’ll have access to:
*   **[Ask Devin](https://docs.devin.ai/work-with-devin/ask-devin)** - Ask questions about your codebase and get detailed, accurate answers powered by advanced code search. You can also use Ask Devin to scope and plan tasks.
*   **[DeepWiki](https://docs.devin.ai/work-with-devin/deepwiki)** - Explore auto-generated documentation for your repositories

For best results, index the branches your team actively develops on. This ensures Ask Devin and DeepWiki have the most up-to-date understanding of your code.
