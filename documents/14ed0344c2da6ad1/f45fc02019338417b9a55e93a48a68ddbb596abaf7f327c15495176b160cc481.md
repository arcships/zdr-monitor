## [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#%E4%B8%89%E3%80%81%E4%BA%A7%E5%93%81%E7%AE%80%E4%BB%8B) 三、产品简介

讯飞星辰 MaaS 平台 Coding Plan 是面向开发者的按月畅享的 AI 编码订阅服务，整合了星火和GLM、Kimi 、MiniMax、DeepSeek、Qwen等开源热门模型（受开源协议等法律责任限制，支持模型以讯飞星辰MaaS平台实际上架为准）。开发者通过订阅包月使用的方式有效防范了欠费风险，使用成本远低于常规 API 调用。 支持通过 OpenAI 协议与 Anthropic 协议接入，兼容 OpenClaw、Cursor、Claude Code 等主流 AI 编程工具，覆盖代码编写、理解与优化等场景，助力提升开发效率与代码质量。

**举例说明**：

用户于26-04-13 10:09:30，完成了套餐订单支付，流控策略如下：

*   五小时流控，订阅生效后，此刻会校验26-04-13 05:09:30 至 26-04-13 10:09:30 的用量，下一次刷新时间是26-04-13 11:00:00；
*   周流控，订阅生效后，此刻会校验26-04-06 10:09:30 至 26-04-13 10:09:30的用量，下一次刷新时间是26-04-14 08:00:00；
*   月限额，有效期为：26-04-13 10:09:30 至 26-05-14 10:09:30。

**波谷系数**

2026年6月18日上线波谷系数，分时段差异化计量，错峰使用即可享受优惠费率，具体计费规则如下：

Coding Plan速率限制会根据资源情况动态调整。高峰期使用Astron Coding Plan可能会出现请求超限情况，建议您间隔一段时间后重试或者更换其他模型。 **请注意**：如在多个实例上同时开启 OpenClaw（例如在多台机器或多个容器中运行），可能会触发平台限流策略，从而出现限流报错。

#### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#_4-1-4-%E5%A5%97%E9%A4%90%E4%BD%BF%E7%94%A8%E5%9C%BA%E6%99%AF%E9%99%90%E5%88%B6) 4.1.4 套餐使用场景限制

Coding Plan 额度仅限在 **编程工具**（如 Claude Code、Open Code、Cursor、OpenClaw 等）的交互式编码场景中使用。  
 禁止将 Coding Plan 的 API Key 用于：

*   自动化脚本、批量任务
*   自建应用后端或服务端
*   任何非交互式、非编程工具场景的调用

违规或滥用可能导致限流、订阅停用或账号注销，请合理使用。

#### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#_4-1-5-%E5%A5%97%E9%A4%90%E9%A2%9D%E5%BA%A6%E6%B6%88%E8%80%97%E8%AF%B4%E6%98%8E) 4.1.5 套餐额度消耗说明

单次提问将按实际“模型调用次数”扣除额度。 作为参考：简单任务约消耗 3-10 次，复杂任务约 10-30+ 次。 实际消耗次数的影响因素有任务难度、上下文及工具使用的数量和情况。 在 [讯飞星辰 MaaS 平台套餐订阅页面(opens new window)](https://maas.xfyun.cn/packageSubscription) 可以查看套餐用量。

### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#_5-2-%E5%A5%97%E9%A4%90%E5%8D%87%E7%BA%A7%E4%B8%8E%E5%8F%A0%E5%8A%A0) 5.2 套餐升级与叠加

*   升级：套餐仅支持升级至速通版，升级费用按当前生效套餐剩余天数折算差价。

*   降级：不支持当前生效套餐从高效版或专业版降级，如需降级使用，需等待当前生效套餐到期后，重新购买更低套餐。

### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#q1-%E5%A6%82%E4%BD%95%E5%88%87%E6%8D%A2%E5%BA%95%E5%B1%82%E6%A8%A1%E5%9E%8B) Q1：如何切换底层模型？

在[讯飞星辰 MaaS 平台套餐订阅页面(opens new window)](https://maas.xfyun.cn/packageSubscription)，点击配置模型（支持在控制台页面配置模型，或通过配置文件指定模型）1-3 分钟后生效。

### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#q2-api-key-%E6%8A%A5%E9%94%99%E6%80%8E%E4%B9%88%E5%8A%9E) Q2：API Key 报错怎么办？

*   确认 Key 来自「套餐订阅」页面，非平台其他服务
*   确认 Base URL 正确（OpenAI 协议用 `https://maas-coding-api.cn-huabei-1.xf-yun.com/v2`，Anthropic 协议用 `https://maas-coding-api.cn-huabei-1.xf-yun.com/anthropic`）
*   确认 model ID 使用 **astron-code-latest**
*   确认套餐未过期或额度未用尽

### [#](https://www.xfyun.cn/doc/spark/CodingPlan.html#q3-%E6%94%AF%E6%8C%81%E5%93%AA%E4%BA%9B%E7%BC%96%E7%A8%8B%E5%B7%A5%E5%85%B7) Q3：支持哪些编程工具？

Claude Code、OpenClaw、Cursor、OpenCode 等支持 OpenAI/Anthropic 协议的工具均可接入。更多其它工具是否支持接入讯飞星辰astron coding plan，可咨询工具提供方确认。
