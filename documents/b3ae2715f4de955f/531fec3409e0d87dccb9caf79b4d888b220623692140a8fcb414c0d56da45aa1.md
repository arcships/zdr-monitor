# GPU Instance FAQ

> Frequently asked questions about GPU instances on Novita AI.

## Instance Management

### How do I create a multi-GPU instance (e.g., 5× A100)?

Select your desired GPU quantity directly on the instance creation page when configuring your instance.

### What should I do if my instance fails to start?

Attempt to migrate the instance first using the **Migrate** option in the console. If no migration option is available, or the issue persists, contact customer support for further assistance.

### How long is data retained after an instance stops?

Data from stopped instances is retained for **7 days**, during which storage fees of **\$0.005/GB/day** apply. After 7 days, data is automatically and permanently deleted with no recovery option.

<Warning>
  We recommend using [Network Volume](/guides/gpu-instance-quickstart-manage-network-volume) for any data with high persistence requirements, as network volume data persists independently of the instance lifecycle.
</Warning>

### Can I change the IP address or endpoint URL for a monthly subscription instance?

Direct IP/URL changes are not supported for active subscriptions. To obtain a new instance with a different address, you must first cancel your current monthly subscription and create a new instance.

### Is ComfyUI supported on GPU instances?

Yes. ComfyUI is supported. Relevant pre-built images are available in the image repository on the instance creation page. You may also upload and use a custom image.

## Connectivity

### My SSH connection fails but the instance status shows as running. What should I do?

This is often a local SSH client or VSCode configuration issue. Try connecting directly via terminal SSH (instead of through VSCode Remote SSH) to isolate the problem. If the issue persists, check the instance logs in the console or <a href="https://discord.gg/YyPRAzwp7P" target="_blank">contact us</a>.

### Can I start or stop Web Terminal via API?

No. Web Terminal operations are only available through the manual controls in the Novita console. API-based control of Web Terminal is not currently supported.

## Storage

### How do I expand local storage capacity?

Contact customer support with your instance IP address and the required capacity (e.g., 30 TB or 60 TB). Our team will provide a custom quote and assist with the expansion.
