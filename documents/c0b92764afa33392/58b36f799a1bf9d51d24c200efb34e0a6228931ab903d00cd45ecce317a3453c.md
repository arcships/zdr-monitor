Title: Codebuff

URL Source: https://www.codebuff.com/docs/advanced/how-does-it-work

Markdown Content:
Codebuff runs multiple agents, each tuned for a specific task.

The main agent ("Buffy") runs on Claude Opus 4.7. It reads your prompt, gathers context, and spawns subagents. The orchestrator is available in several variants:

*   [`base2`](https://www.codebuff.com/publishers/codebuff/agents/base2) - Default mode orchestrator
*   [`base2-lite`](https://www.codebuff.com/publishers/codebuff/agents/base2-lite) - Lite mode (faster, cheaper)
*   [`base2-max`](https://www.codebuff.com/publishers/codebuff/agents/base2-max) - Max mode (best-of-N selection)
*   [`base2-plan`](https://www.codebuff.com/publishers/codebuff/agents/base2-plan) - Plan mode (no file writes)

*   [**File Picker**](https://www.codebuff.com/publishers/codebuff/agents/file-picker) (Gemini 2.0 Flash) - finds relevant files
*   [**Code Searcher**](https://www.codebuff.com/publishers/codebuff/agents/code-searcher) - grep-style pattern matching
*   [**Researcher**](https://www.codebuff.com/publishers/codebuff/agents/researcher) (Gemini 3.1 Flash Lite) - web and docs lookup
*   [**Thinker**](https://www.codebuff.com/publishers/codebuff/agents/thinker) (Claude Opus 4.7, GPT-5.4) - works through hard problems
*   [**Editor**](https://www.codebuff.com/publishers/codebuff/agents/editor) (Claude Opus 4.7, GPT-5.1) - writes and modifies code
*   [**Reviewer**](https://www.codebuff.com/publishers/codebuff/agents/reviewer) (Claude Opus 4.7, GPT-5.6 Luna in Lite mode) - catches bugs and style issues
*   [**Basher**](https://www.codebuff.com/publishers/codebuff/agents/basher) (Gemini 3.1 Flash Lite) - runs terminal commands

In Max mode, Codebuff spawns multiple editors with different strategies. A selector compares the outputs and picks the best one.

1.   Tree-sitter scans your repo and builds a code map
2.   File pickers and searchers find relevant code
3.   Thinkers analyze the problem if needed
4.   Editors generate changes
5.   Reviewers check for issues; bashers run tests

Edits and commands run locally. Relevant prompts, code, files, and repository context are sent to Freebuff and model providers. See the [Privacy Policy](https://freebuff.com/privacy-policy).
