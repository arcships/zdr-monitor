Token Plan 企业版套餐是面向企业客户的大模型订阅套餐，覆盖龙虾助手与 AI Coding 双场景，满足团队管理、预算可控的核心诉求，助力企业 AI 规模化应用与协作提效。产品包含 [企业版专业套餐](https://cloud.tencent.com/document/product/1823/130659)**（原 Token Plan 企业版）**和 [企业版轻享套餐](https://cloud.tencent.com/document/product/1823/131173) 两种不同套餐类型，适配不同企业使用需求。

**说明：**

Token Plan 企业版与个人版独立管理，个人版套餐详情请参见 [Token Plan 个人版套餐概览](https://cloud.tencent.com/document/product/1823/130060)。

## 产品优势

**优势****说明**
一站畅享主流大模型**企业版专业套餐：**当前支持 Auto 智能路由模型、 GLM、Kimi、MiniMax、DeepSeek 多家模型，平台将持续更新。

**企业版轻享套餐：**仅支持 Auto 智能路由模型，平台通过算法自动匹配模型。

**说明：**

平台将根据产品规划与服务优化需求，不定期对模型进行迭代，如有上新或下线调整，相关变更将通过平台另行通知。
兼容主流 AI 编程工具和龙虾工具 支持 OpenClaw、Claude Code、OpenCode、Cline、Cursor 等 AI 工具，共享套餐额度，让龙虾随时随地干活，体验 AI 编码自由。
高 TPM 上限，流畅并发调用 提供更高 TPM 上限，多龙虾并发调用更稳定，复杂场景下也能体验流畅。

**说明：**

受网络环境、硬件负载、突发流量等客观因素影响，极端情况下可能存在服务波动。
包月订阅，成本可控 按月预算购买积分池/ Token 池，调用时按实际用量实时扣减，便于提前锁定资源并精细化管理成本。
即开即用，极简流程 完成支付、获取 API Key 后即可快速接入，无需复杂配置。
多维团队管理，协作高效 支持多套餐管理、多 Key 分配、独占积分及限额控制，用量明细与趋势实时可见。
数据安全 数据安全保障，不使用用户请求与模型返回数据进行模型训练，满足企业级数据隐私要求。

**说明：**

由 DeepSeek 直接提供的 DeepSeek V4 Flash（deepseek-v4-flash）、 DeepSeek V4 Pro（deepseek-v4-pro） 模型服务，TokenHub 不对该服务提供 SLA 保障。使用该模型即视为您已知晓并同意遵守 [DeepSeek 的服务协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-terms-of-use.html)，请您在使用前务必仔细阅读相关内容，如不接受上述内容，请立即停止使用。

## 产品对比

**企业版专业套餐（原 Token Plan 企业版）**和**企业版轻享套餐**的主要区别请参考下表：

**产品类别****企业版专业套餐****企业版轻享套餐**
可用模型 Auto 智能路由模型、GLM、Kimi、MiniMax、DeepSeek 多家模型，详见 [模型列表](https://cloud.tencent.com/document/product/1823/130659#cde5404a-a7bb-4d53-acba-6e3b1b6b8264)。Auto 智能路由模型
套餐包额度单位 积分 Token
计费方式 预付费购买包月积分池。

调用模型时，按各模型的 Token 消耗从积分池中实时扣减，不同模型抵扣系数不同，各个模型抵扣规则请参见 [专业套餐详情](https://cloud.tencent.com/document/product/1823/130659#156be2f3-69df-483c-8187-6af016bc8c04)。预付费购买包月 Token 池。
