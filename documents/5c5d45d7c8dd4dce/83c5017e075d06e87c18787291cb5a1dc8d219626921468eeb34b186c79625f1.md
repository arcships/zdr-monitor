# GPU Droplet Availability by Region

DigitalOcean Droplets are Linux-based virtual machines (VMs) that run on top of virtualized hardware. Each Droplet you create is a new server you can use, either standalone or as part of a larger, cloud-based infrastructure.

DigitalOcean GPU Droplets, Spot GPU Droplets, and Bare Metal GPUs are available by GPU model and datacenter as listed below. For pricing, see [GPU Droplet pricing](https://docs.digitalocean.com/products/droplets/details/pricing/index.html.md). For hardware specifications and model comparisons, see the [GPU product comparison](https://docs.digitalocean.com/products/bare-metal-gpus/concepts/gpu-product-comparison/index.html.md).

## On-Demand GPU Droplets

DigitalOcean offers AMD Instinct MI300X, NVIDIA H100, NVIDIA H200, NVIDIA L40S, NVIDIA RTX 4000 Ada, and NVIDIA RTX 6000 Ada GPU Droplets across 4 datacenters.

### AMD Instinct MI300X

AMD Instinct MI300X GPU Droplets are available in Atlanta (ATL1).

### NVIDIA H100

NVIDIA H100 GPU Droplets are available in New York (NYC2), Amsterdam (AMS3), and Toronto (TOR1).

### NVIDIA H200

NVIDIA H200 GPU Droplets are available in New York (NYC2) and Atlanta (ATL1).

### NVIDIA L40S

NVIDIA L40S GPU Droplets are available in Toronto (TOR1).

### NVIDIA RTX 4000 Ada

NVIDIA RTX 4000 Ada GPU Droplets are available in Toronto (TOR1).

### NVIDIA RTX 6000 Ada
