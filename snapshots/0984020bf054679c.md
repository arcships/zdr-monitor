# Overview
Updated at: 2026-09-21 15:55:08
Copy as MD
Product
Token Plan Team Edition is an AI large model subscription service offered by Alibaba Cloud Model Studio. It uses Credits as a unified billing unit, supports text generation, image generation, video generation, speech recognition, and real-time voice conversation models, is compatible with mainstream AI coding and agent tools, and provides a team management console, data security guarantees, and stable service operation.
**Note**
Token Plan Team Edition currently supports only the **Singapore** region.
## Product overview
Token Plan Team Edition integrates Qwen and third-party models, supporting text generation, image generation, video generation, speech recognition, and real-time voice conversation. It uses Credits as a unified billing unit, allowing one subscription to be used across multiple AI tools.
- **Flexible model switching**: Switch between multiple models on demand, with unified Credits deduction.
- **Compatible with multiple tools**: Works with mainstream coding tools and popular agent tools. The console provides quick access to AI tools, supporting Qwen Code, Claude Code, Qoder, Qoder CN, OpenClaw, and more.
- **Multiple plan tiers**: Offers Standard, Advanced, and Premium seat tiers to match different usage intensities.
- **Team management**: Provides an admin console with capabilities such as seat assignment and reclamation, and member usage analytics.
- **Predictable budget**: Supports monthly subscriptions for predictable budgeting.
- **Data security**: Conversation data is not used for model training, meeting enterprise-grade data privacy requirements.
- **Stable operation**: Multi-tenant isolation architecture ensures no queuing during peak usage periods.
Token Plan Team Edition provides a separate Base URL compatible with OpenAI and Anthropic API standards. You can find the specific address in the API Key section of **My Subscriptions** in the console.

Alibaba Cloud Model Studio reserves the right to modify or adjust promotions based on operational needs, including but not limited to promotion details and validity periods. Please refer to the latest page content or Alibaba Cloud notifications.

## Plans and pricing
Go to the Token Plan Team Edition purchase page to select the seat type, quantity, and subscription period to complete your subscription. Both primary accounts and RAM accounts can subscribe. Subscription periods include monthly and auto-renewing monthly options.
### Token Plan Team Edition
Three seat tiers are available: Standard, Advanced, and Premium, to match different usage intensities.
A seat is the minimum subscription unit of Token Plan Team Edition, representing a usage quota for one team member. After an administrator assigns a seat to a member in team management, the system automatically generates an individual API Key for that member. Each seat is bound to one member and corresponds to one API Key, and cannot be shared.

### Token Plan Team Edition - Shared Usage Pack
A flexible usage pack shared across seats. When an individual seat's usage exceeds its plan quota, the overage is deducted from the shared usage pack. Each shared usage pack is valid for 1 month, and unused quota expires automatically at the end of the period. When multiple shared usage packs are held, the one expiring soonest is consumed first. Owners and administrators can set a shared usage pack quota limit per member to control individual consumption. See Team management.

## Credits billing mechanism
### Billing description
The Credits consumed per request are dynamically determined by factors such as the model type, token usage, thinking mode, and tool calls. Actual consumption is subject to the usage details on the subscription page in the console.

### Deduction order
1. Credits are first deducted from the seat plan's monthly quota.
2. After the seat quota is exhausted, Credits are deducted from the shared usage pack. When multiple shared usage packs are held, the one expiring soonest is consumed first.
3. After all quotas are exhausted, the service is suspended until the next billing cycle or until a shared usage pack is purchased to replenish the quota.
## View quota consumption
**Via the console**: Log in to the Token Plan console and go to the **My Subscriptions** page to view the overall quota usage percentage, reset time, team seat allocation, and the status and expiration date of each seat and shared usage pack.
**Via the team management portal**: On the **Usage Analytics** page, you can view Credits consumption trends for the past 1, 7, or 30 days, usage by model, and consumption details for each member. For more information, see Team Management.
## Subscription management
### Add seats
On the **My Subscriptions** page in the Token Plan console, click **Add Seats**, select the seat tier and quantity, and submit the order. New seats share the same expiration date as the existing subscription, and the cost and Credits quota are prorated based on the remaining duration.
### Upgrade seats
In **Subscription Details**, find the target seat and click **Upgrade**, then select a higher tier and submit the order. For bulk operations, select multiple seats and click **Batch Upgrade**. The upgrade cost is the prorated price difference for the remaining duration.
### Renewal
- Click the **Renew** button. The renewal period matches the subscription period. Complete the renewal before expiration to avoid service interruption.
- **Auto-renewal**: Click **Enable Auto-Renewal** and confirm. It takes effect the next day. The system automatically charges and renews 3 days before expiration according to the subscription period. To disable, click **Disable Auto-Renewal** and confirm.
### Unsubscribe seats
In **Subscription Details**, click **Unsubscribe** for a seat to unsubscribe on a per-seat basis. Seats with existing usage consumption cannot be unsubscribed. You can also select multiple seats and click **Batch Unsubscribe**. Refunds are returned to the original payment account within an estimated 1-3 business days.
### Purchase shared usage packs
In the **Shared Usage Pack** section, click **Go to Purchase**.
### Important notes
- After unsubscribing and resubscribing, the API Key and Base URL will change and must be reconfigured in your tools. Your new API Key and Base URL can be found in the **My Subscription** page in the console under the API Key section.
- Renewal only extends the subscription period and does not add to the current billing cycle's quota.
- The Team Edition and Personal Edition can be held simultaneously, each billed independently.
## Usage policy
1. **Scope of use**: For interactive use only within compatible AI coding and agent tools. Not permitted for automated scripts or application backends. Violations may result in subscription suspension or API Key revocation.
2. **Data security**: Token Plan Team Edition does not use conversation data for model training.
3. **Account policy**: API Keys are restricted to the assigned seat holder and must not be shared or publicly disclosed.
4. **Service region**: Token Plan Team Edition is currently available in specific regions only. If you need to call the service from outside mainland China, ensure compliance with local laws and regulations.
