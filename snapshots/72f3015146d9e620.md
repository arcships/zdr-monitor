# 2.什么是个人信息？
在本隐私条款下，“个人信息”是指单独使用或结合小米可获取的有关该个人的其他信息后，能够直接或间接识别个人身份的信息，除非您所在地区的适用法律另有特殊规定。它包括姓名、联系方式、身份识别号码、位置数据或在线标识符（例如，小米账户 ID）等信息。我们将严格按照本隐私条款使用您的个人信息。
# 3.我们收集哪些信息以及用于什么目的？
## 3.1.向您收集个人信息
收集个人信息的目的在于向您提供本产品及相关服务。为此，我们将处理以下个人信息：
- 登录您的小米账户
您需要登录您的小米账户才能访问 Xiaomi MiMo 平台的相关功能。为此，我们将收集您的账户 ID、手机号码或电子邮件地址，并创建一个 API Key，以便在提供应用程序接口服务时验证和显示您的身份。
- 应用程序接口服务
如果您使用应用程序接口服务，我们将收集您的 IP 地址 and您提交的内容（文本、音频、视频、图片），以根据您选择的模型分析相关指令并生成返回的内容。小米不会将您提供的内容用于模型训练或任何其他目的。当您使用预付费应用程序接口服务时，我们将收集您的充值信息和交易记录。当使用声音克隆功能时，我们需要收集您提供的音频文件及其包含的声纹信息，以便基于音频中的语音音色生成内容。您必须确保您已获得信息主体对使用其个人信息的合法、充分和明确的同意（如果涉及敏感个人信息，必须获得单独同意）。您不得上传任何违法、违规或侵犯他人权益的音频内容。您授权 Xiaomi MiMo 受托处理您上传的信息以提供该服务，且 Xiaomi MiMo 无需从任何其他方获得任何额外的授权。
- 反馈
当您向我们提供反馈时，我们将收集您的联系信息（电话号码、电子邮件）以及您提交的信息（包括屏幕截图）。
- 通知
为了向您提供余额提醒、消息通知服务，我们将通过您提供的联系信息（例如手机号码、电子邮件）向您发送通知。当您参与平台上的促销活动时，我们将收集您的电子邮件地址，以发送通知、发放奖励并提供相关的后续服务。
## 3.2.从第三方源收集个人信息
小米产品及服务可能需要先创建小米账户个人资料。为了更快速地登录或轻松完善小米账户个人信息，您还可以授权将第三方账户（例如您的谷歌、Facebook 或 Apple 账户）与您的小米账户进行绑定。经您同意，您授权该第三方账户将您的头像、昵称、电子邮件和其他信息导入您的小米账户。 请注意，我们将通过加密等手段确保您的信息安全，但第三方对您个人信息的处理受该相关第三方的隐私条款约束。因此，我们建议您阅读第三方的隐私条款，就像您阅读我们的隐私条款一样。您可以随时通过 https://account.xiaomi.com/ 上的“账户与权限”取消对第三方的授权。
## 3.3.非个人身份识别信息
我们还会收集其他与个人无直接或间接关联且根据适用法律可能不被定义为个人信息的信息。此类信息被称为非个人身份识别信息，我们可能会收集、使用、传输、披露和以其他方式处理此类非个人身份识别信息。此类信息可能包括您使用特定服务时生成的统计数据，例如日常使用事件、页面访问事件、页面访问时间事件、会话事件（当不被视为个人信息时）等交互记录，以及您使用我们服务时的错误记录。此类收集的目的在于改进我们向您提供的服务（例如，用于纠正网页错误）。所收集信息的类别和数量取决于您如何使用我们的服务。我们汇总此类信息。在汇总的形式下，这些数据不是个人信息，无法用于识别您的身份。但是，如果将非个人身份识别信息与个人信息相结合，则在结合期间，此类非个人身份识别信息将根据本隐私条款被视为个人信息。
