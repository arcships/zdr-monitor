## [术语与定义]
在本协议中，除非另有说明，下列术语具有如下含义：
1. **PocketClaw 硬件设备（或称"PocketClaw"）：** 指由我们销售的、用于运行 PocketClaw 系统软件及存储用户数据的物理计算设备。
2. **本地存储：** 指数据物理存放于 PocketClaw 硬件内置的存储介质中，而非存储于我们的云端服务器。
3. **管理访问（Administrative Access）：** 指用户通过 Web 浏览器或客户端对硬件进行系统配置、智能体编排及知识库管理的行为。**该行为默认仅限在局域网（LAN）环境下进行。**
4. **智能体交互（Agent Interaction）：** 指用户通过第三方即时通讯工具（如微信、飞书、钉钉等）与部署在硬件上的智能体进行指令下达与消息往来的行为。
5. **模力方舟（Moark）：** 指由深圳奥思研工智能科技有限公司提供的模型集成与算力调度平台（MaaS），作为本产品的可选官方算力支持。
6. **第三方服务（Third-Party Services）：** 指除我们以外的其他主体提供的模型 API（如阿里云通义千问、DeepSeek 等）、MCP 服务器插件、外部数据库或集成工具。
## 一、产品定义与服务范围
1. **产品定义：** "**PocketClaw**" 是指由我们研发的集硬件主机、固件（Firmware）及客户端软件（PocketClaw 应用）于一体的智能终端设备。
2. **核心功能：**
- **智能体（Agents）构建：** 提供预设模板和自定义配置，允许用户设置角色、提示词和知识库，以快速创建适用于研究、编程和办公等场景的智能体。
- **多模态对话交互：** 支持文本和图像等多模态输入输出，具备多轮对话理解和上下文记忆，用于日常信息咨询、任务交互和对话管理。
- **可视化工作流编排：** 提供拖拽式任务流配置界面，支持顺序、分支、并行和循环等逻辑控制，允许用户将多个智能体或功能模块串联为自动化处理链路。
- **智能调度与任务管理：** 提供基于定时触发（Cron）或特定事件驱动的任务调度能力，支持任务状态跟踪和持久化存储，保障自动化流程的周期性或实时运行。
- **跨平台即时通讯（IM）集成：** 支持将智能体接入微信、企业微信、飞书、钉钉等主流社交和办公 IM 通道，实现跨平台的指令下达和消息交互。
- **自定义技能扩展与生态连接：** 集成 ClawHub 社区资源，支持用户通过 Python/Node.js 开发自定义技能，并支持通过 MCP 服务器协议对接 GitHub、本地文件系统、数据库等外部工具。
- **自治式智能助手（Hand 系列）：** 提供具备自主操作能力的预设插件包（如 Browser Hand、Researcher Hand 等），支持智能体自主完成网页浏览、信息搜集、数据分析及趋势预测等复杂任务。
- **多模型引擎灵活接入：** 支持模力方舟、阿里通义千问等主流大模型提供商的 API 接入与配置，允许用户根据任务需求灵活切换不同的底层模型引擎。
> 具体功能以产品实际提供的当前版本为准，PocketClaw 持续优化迭代，部分功能的开放范围可能受制于特定平台规则。
1. **服务构成：** 包括硬件销售、预装软件许可、软件在线升级（OTA）以及由我们提供的 **"模力方舟" AI 模型接入服务（MaaS）**。

## 四、隐私政策与数据处理
我们高度重视您的隐私，对您的隐私信息与数据处理具体规则如下：
1. **信息收集：**
- **设备信息：** 为识别设备身份，我们可能收集硬件序列号、MAC 地址、系统版本号。
- **日志信息：** 在您授权下，收集系统崩溃记录以改进性能。
2. **数据存储：**
- **本地化原则：** PocketClaw 核心数据（如原始知识库、配置文件、系统日志）执行本地化存储策略，均物理存储于您的 PocketClaw 硬件中。
- **访问限制：** **本产品不提供针对硬件管理后台的远程穿透或官方云端中继服务。** 在非局域网环境下，您可能无法直接登录管理面板或进行系统底层配置。
- **IM 交互例外：** 若您启用了"跨平台即时通讯（IM）集成"功能，您可以通过第三方 IM 平台（如微信、飞书、钉钉等）与您部署的智能体进行交互。**请知悉，此类交互依赖于第三方平台的网络可达性及 API 回调机制。** 该场景下，仅限对话指令及回复数据经由第三方平台传输，您的底层知识库文件依然保留在本地硬件中。
- **云端交互与 AI 算力：** PocketClaw 硬件及客户端软件不直接提供 AI 算力，需通过网络接入大模型服务（MaaS）。数据流向根据您选择的服务商而定：
- **官方服务（模力方舟）：** 若您选择由本公司提供的"模力方舟"算力服务，您的对话数据将通过加密通道传输至官方服务器。**我们承诺：** 该等数据仅用于实时推理，除非获得您的显式授权或法律法规要求，我们不会对您的对话内容进行持久化存储，亦不会将其用于模型训练。
- **第三方服务：** 若您自行配置第三方大模型 API（如阿里通义千问、DeepSeek 等），您的数据将直接发送至该第三方服务商。**我们不会中转或留存该等数据。** 关于此类数据的处理规则，请您务必阅读并认可该第三方服务商的隐私政策，我们对第三方服务商的行为不承担法律责任。
3. **第三方共享：** 除非获得您的明确同意或法律要求，我们不会将您的个人数据提供给任何第三方。
