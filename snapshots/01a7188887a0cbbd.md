# Supported Dedicated Cloud regions
Copy MCP ServerCopy MCP Server
View all supported AWS, Google Cloud, and Azure regions available for W&B Dedicated Cloud instances.
Copy MCP ServerCopy MCP Server
AWS, Google Cloud, and Azure support cloud computing services in multiple locations worldwide. Global regions help ensure that you satisfy requirements such as data residency, compliance, latency, and cost efficiency. Weights & Biases supports many of the available global regions for Dedicated Cloud. The following sections list the supported regions for each cloud provider.
Reach out to Support if your preferred AWS, Google Cloud, or Azure region isn’t listed. CoreWeave can validate whether the relevant region has all the services that Dedicated Cloud needs and prioritize support depending on the outcome of the evaluation.

| US East (N. Virginia) | `us-east-1` |
| US West (N. California) | `us-west-1` |

| Europe (Frankfurt) | `eu-central-1` |
| Europe (Ireland) | `eu-west-1` |
| Europe (London) | `eu-west-2` |

For more information about AWS regions, see Regions, Availability Zones, and Local Zones in the AWS Documentation. See What to Consider when Selecting a Region for your Workloads for an overview of factors to consider when choosing an AWS region.
