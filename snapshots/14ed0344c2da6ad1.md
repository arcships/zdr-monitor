## # 三、产品简介
讯飞星辰 MaaS 平台 Coding Plan 是面向开发者的按月畅享的 AI 编码订阅服务，整合了星火和GLM、Kimi 、MiniMax、DeepSeek、Qwen等开源热门模型（受开源协议等法律责任限制，支持模型以讯飞星辰MaaS平台实际上架为准）。开发者通过订阅包月使用的方式有效防范了欠费风险，使用成本远低于常规 API 调用。 支持通过 OpenAI 协议与 Anthropic 协议接入，兼容 OpenClaw、Cursor、Claude Code 等主流 AI 编程工具，覆盖代码编写、理解与优化等场景，助力提升开发效率与代码质量。

#### # 4.1.3 套餐额度限制说明
Coding Plan速率限制会根据资源情况动态调整。高峰期使用Astron Coding Plan可能会出现请求超限情况，建议您间隔一段时间后重试或者更换其他模型。 **请注意**：如在多个实例上同时开启 OpenClaw（例如在多台机器或多个容器中运行），可能会触发平台限流策略，从而出现限流报错。
#### # 4.1.4 套餐使用场景限制
Coding Plan 额度仅限在 **编程工具**（如 Claude Code、Open Code、Cursor、OpenClaw 等）的交互式编码场景中使用。
禁止将 Coding Plan 的 API Key 用于：
- 自动化脚本、批量任务
- 自建应用后端或服务端
- 任何非交互式、非编程工具场景的调用
违规或滥用可能导致限流、订阅停用或账号注销，请合理使用。
#### # 4.1.5 套餐额度消耗说明
单次提问将按实际“模型调用次数”扣除额度。 作为参考：简单任务约消耗 3-10 次，复杂任务约 10-30+ 次。 实际消耗次数的影响因素有任务难度、上下文及工具使用的数量和情况。 在 讯飞星辰 MaaS 平台套餐订阅页面 (opens new window) 可以查看套餐用量。

1. 登录讯飞星辰 MaaS 平台，进入 **套餐订阅** 页面。

### # 5.2 套餐升级与叠加
- 升级：套餐仅支持升级至速通版，升级费用按当前生效套餐剩余天数折算差价。
- 叠加：支持在同一档位多次购买，每份叠加对应一个 API Key 与一份日tokens额度（首版）或对应请求次数额度（焕新版）。
- 降级：不支持当前生效套餐从高效版或专业版降级，如需降级使用，需等待当前生效套餐到期后，重新购买更低套餐。

除下列情形以外，Coding Plan套餐服务一经购买，不支持退订退款，请谨慎下单：1.由于平台原因，用户付费后无法获得服务；2.法律法规另有规定。

## # 七、常见问题
### # Q1：如何切换底层模型？
在讯飞星辰 MaaS 平台套餐订阅页面 (opens new window)，点击配置模型（支持在控制台页面配置模型，或通过配置文件指定模型）1-3 分钟后生效。
### # Q2：API Key 报错怎么办？
- 确认 Key 来自「套餐订阅」页面，非平台其他服务
- 确认 Base URL 正确（OpenAI 协议用 `https://maas-coding-api.cn-huabei-1.xf-yun.com/v2`，Anthropic 协议用 `https://maas-coding-api.cn-huabei-1.xf-yun.com/anthropic`）
- 确认 model ID 使用 **astron-code-latest**
- 确认套餐未过期或额度未用尽
### # Q3：支持哪些编程工具？
Claude Code、OpenClaw、Cursor、OpenCode 等支持 OpenAI/Anthropic 协议的工具均可接入。更多其它工具是否支持接入讯飞星辰astron coding plan，可咨询工具提供方确认。
