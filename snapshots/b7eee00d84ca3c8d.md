- 产品优势

Token Plan 企业版套餐是面向企业客户的大模型订阅套餐，覆盖龙虾助手与 AI Coding 双场景，满足团队管理、预算可控的核心诉求，助力企业 AI 规模化应用与协作提效。产品包含 企业版专业套餐**（原 Token Plan 企业版）**和 企业版轻享套餐 两种不同套餐类型，适配不同企业使用需求。
**说明：**
Token Plan 企业版与个人版独立管理，个人版套餐详情请参见 Token Plan 个人版套餐概览。
