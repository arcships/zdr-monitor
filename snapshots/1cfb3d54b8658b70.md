API Privacy & Security
Perplexity’s API Platform is designed to process Customer Content to provide the requested API service. Retention, use, and security practices vary by API, model, and account configuration, so this page should be read together with the API Terms of Service, applicable product-specific terms, the Data Processing Addendum, and any written agreement between you and Perplexity.
- **No training by default:** Under the API Terms of Service, Perplexity does not use Customer Content to train generative AI models. Certain APIs may be subject to product-specific terms.
- **Zero Data Retention is not default:** ZDR is available only to eligible customers through an account-level configuration under a written agreement with Perplexity. If ZDR has not been enabled for your account, do not assume that Perplexity or its model providers apply zero data retention to your requests.
- **Model-specific limitations:** Not every model supports ZDR. Where ZDR is enabled for an Agent API account, only models whose providers support ZDR may be used; requests to unsupported models will return an error.
- **Third-party model terms apply:** Models served by third-party providers are also subject to those providers’ terms and policies. Some providers require limited retention as a condition of offering their models.
- **Service and account data:** Perplexity collects limited usage metadata—such as request and token counts, model used, timestamps, duration, and API key—to operate and bill the service, along with account information such as name and email address.
- **Personal data:** Perplexity processes personal data in accordance with its Data Processing Addendum, and information about subprocessors is available on Perplexity’s Trust Center.
This section is provided for convenience and does not modify the API Terms of Service, product-specific terms, the Data Processing Addendum, third-party model provider terms, or any other agreement between you and Perplexity. Where those documents differ, they control.
