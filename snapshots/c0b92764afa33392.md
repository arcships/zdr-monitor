# How does Codebuff actually work?
Codebuff runs multiple agents, each tuned for a specific task.
## The Orchestrator
The main agent ("Buffy") runs on Claude Opus 4.7. It reads your prompt, gathers context, and spawns subagents. The orchestrator is available in several variants:
- `base2` - Default mode orchestrator
- `base2-lite` - Lite mode (faster, cheaper)
- `base2-max` - Max mode (best-of-N selection)
- `base2-plan` - Plan mode (no file writes)
## Subagents
- **File Picker** (Gemini 2.0 Flash) - finds relevant files
- **Code Searcher** - grep-style pattern matching
- **Researcher** (Gemini 3.1 Flash Lite) - web and docs lookup
- **Thinker** (Claude Opus 4.7, GPT-5.4) - works through hard problems
- **Editor** (Claude Opus 4.7, GPT-5.1) - writes and modifies code
- **Reviewer** (Claude Opus 4.7, GPT-5.6 Luna in Lite mode) - catches bugs and style issues
- **Basher** (Gemini 3.1 Flash Lite) - runs terminal commands
## Best-of-N Selection (Max Mode)
In Max mode, Codebuff spawns multiple editors with different strategies. A selector compares the outputs and picks the best one.
## The Pipeline
1. Tree-sitter scans your repo and builds a code map
2. File pickers and searchers find relevant code
3. Thinkers analyze the problem if needed
4. Editors generate changes
5. Reviewers check for issues; bashers run tests
Edits and commands run locally. Relevant prompts, code, files, and repository context are sent to Freebuff and model providers. See the Privacy Policy.
